# Simple temperature/humidity measurement

Station with local measurement and using data for temp from internet
build on ESP32 and additional this

Project suppose to make:

- [x] Temp and humidity measurement in building
- [] Diff menus with button control
- [] Take temp and humidity from region
- [] Have an fancy display saving capabilities

Things which used in this project:

  1. Board ESP32-S3-DevkitC-1, Documentaion:[url](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html#getting-started)
  2. Temperature/Humidity sensor SHT21, Documentation:[url](https://sensirion.com/media/documents/120BBE4C/63500094/Sensirion_Datasheet_Humidity_Sensor_SHT21.pdf)
  3. Display OLED SSD1306 White, Documentation: [url](https://www.waveshare.com/w/upload/9/95/SSD1306.pdf)
  4. Button & Joystick KY-023, Documentation: [url](https://naylampmechatronics.com/img/cms/Datasheets/000036%20-%20datasheet%20KY-023-Joy-IT.pdf)
